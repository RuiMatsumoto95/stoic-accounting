# 勘定科目マスタ

`/accounts` で、選択中の会社の勘定科目と補助科目を登録・編集・削除する。共通ナビゲーションの項目には含まれていないため、`/accounts` を直接開く。

## 一覧と登録

- 一覧は科目コード順の親科目と、その直下の補助科目を表示する。「＋ 新規登録」または各行の編集ボタンで入力欄を開く。
- 親科目では科目コード・科目名・科目区分・財務諸表区分が必須。法人と個人で表示する区分候補が異なる。例えば個人ではB/Sの資産に事業主貸、負債に事業主借を選べる。
- 新規登録で親科目を指定すると、補助科目のコードを「親コード-4桁」で自動入力する。既存の同じ親の該当コードから最大の末尾番号を取り、1を足す。補助科目の編集時は末尾4桁を入力でき、親・科目区分・財務諸表区分は固定表示。科目区分と財務諸表区分はDBで親から継承する。
- デフォルト税区分は「設定なし」または6つの税区分グループ。例として「対象外」の `NONE` は、この欄を未設定にする操作とは別の保存値。

## 別名と削除

- 「読み方・別名」では、かな・ローマ字・略称などを登録できる。科目名と別名は仕訳入力の候補検索に使われる。既存の補助科目を編集するダイアログでは別名の編集欄を表示しない。
- 削除は確認ダイアログを経て行う。仕訳や期首残高などからの参照によってDBが削除を拒否する場合は、画面にエラーを表示する。テンプレート明細の任意の科目参照は、参照先が削除されるとNULLになる。

## 制約

科目と別名は別リクエストで保存する。科目の保存後に別名の更新が失敗すると、科目または一部の別名の変更が残り得る。会社の切り替えを検出するため、別名の後続リクエスト前にも作業中の会社を照合する。
