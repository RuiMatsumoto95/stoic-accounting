# 仕訳日記帳

`/journals` では、選択中の会社と当期の仕訳を入力・検索し、一覧から訂正・複製・削除する。画面下部の入力欄と一覧を使い、複合仕訳の編集・複製は上部のフォームで行う。

## 新規入力と保存

- 一覧下部の日付・借方・貸方・摘要・補足の欄に入力する。初期状態は借方1行と貸方1行。「借方+」「貸方+」で明細を増やせる。仕訳で補助科目を選んだ場合、明細には補助科目のIDを保存する。
- 日付は月日3〜4桁または `M/D` 形式で入力でき、会計期の開始月を基準に年を解決する。金額は正の数で、小数第2位まで。借方と貸方が一致することを画面とDBで確認する。税区分候補は会社の事業者タイプに応じて絞る。
- 借方・貸方が各1行の入力・インライン編集では、金額欄を離れたときや保存時に反対側を補う。変更した金額が正で、反対側が空または変更前の金額と同じときにコピーする。反対側に別の金額がある場合はその入力を保つ。複合仕訳では自動コピーしない。
- 新規入力は末尾に仮の行を表示し、保存が完了するとDBから返った正式IDと伝票番号に差し替える。採番中の番号は「…」。失敗時は仮の行を除いてエラーを通知する。
- 伝票番号は会計期ごとの自動採番。既存仕訳の編集は番号を手入力でき、空欄で保存すると元の番号を維持する。複合仕訳フォームにも番号欄があり、新規扱いの複製では空欄なら採番する。既存の番号なしの仕訳は一覧で「-」と表示する。[採番・保存のDB仕様](../20-database/functions-rpc.md#仕訳保存と伝票番号) を参照。

## 一覧の検索と並び順

- 検索条件は日付の範囲、明細金額の範囲、摘要の部分一致、科目。親科目を指定するとその補助科目も含む。金額と科目を両方指定した場合、同じ明細が両方の条件を満たす仕訳を表示する。検索条件はURLに反映し、「クリア」で解除する。
- DB取得時は日付 → 伝票番号（数値順・空欄は最後）→ 作成日時 → IDの昇順。新規保存は検索条件にかかわらず画面の末尾に追加し、最後の表示範囲へ移す。単純仕訳の編集後は、結果に残る仕訳の並びを維持する。検索やF5で取得順に並び直す。
- 通常は最大12表示行を表示する。複合仕訳の明細は、借方・貸方をそれぞれ行番号順にそろえて並べる。1仕訳の明細を表示範囲の境界で分割せず、13行以上の仕訳もまとめて表示する。
- 一覧の右端のボタンで、仕訳ごとの補足を開閉する。補足は仕訳単位で、検索条件には含まれない。

## 訂正・複製・削除

- 単純仕訳の編集は一覧内、複合仕訳の編集は上部のフォームで行う。インライン編集ではEnterや欄外クリックで保存でき、Tabも原則として保存して移動する。摘要から補足へのTabと、補足から摘要へのShift+Tabは保存せず移動する。Escで編集を取り消す。保存に失敗した場合は入力を残して理由を表示する。
- 「複製」は日付、明細、摘要、補足を引き継ぐ。単純仕訳は下部の入力欄に反映し、入力途中の内容を上書きして日付欄へ移動する。複合仕訳は上部のフォームで開く。いずれも元の伝票番号は引き継がない。
- 「日付・摘要を変更」はチェックした仕訳のうち、指定した日付と摘要（片方または両方）を一括更新する。指定できる日付は当期内。単独削除・一括削除には確認ダイアログがある。全選択は表示範囲の仕訳が対象。
- 期首残高仕訳のフラグが付いた仕訳は画面で編集・削除・複製・一括選択の対象外。確定済みの期は入力・編集・複製・削除を無効にする。後続の会計期の期首残高が自動計算の場合は、仕訳変更の影響を知らせる案内が出る。[期首残高](opening-balances.md) と [年度の確定と解除](settings.md#年度の確定と解除) を参照。

## キーボード操作

| 操作 | 動作 |
| --- | --- |
| 矢印、Tab／Shift+Tab | 一覧のセル間を移動する。 |
| Enter、F2、ダブルクリック | 一覧の仕訳を編集する。日付・金額では数字、科目・摘要では文字を打って編集を始められる。 |
| Alt+↓ | 借方・貸方の科目セルから候補を開く。その他のセルでは補足を開閉する。 |
| Space、Delete | 一覧で仕訳を選択・解除する。または削除の確認を開く。 |
| Ctrl+Shift+E／L／R／S | 入力欄の日付へ移動／借方行追加／貸方行追加／保存。上部フォームを開いている場合は、保存が上部フォームに作用する。 |
| Ctrl+↑／Ctrl+↓ | 一覧の先頭側／末尾側へ移動する。Ctrl+↓は上部フォームを開いていなければ下部入力欄の日付に移動する。 |
| F5 | 現在の検索条件で一覧だけを取り直し、表示範囲と一覧セルの位置を可能な範囲で復元する。インライン編集中・上部フォーム表示中・取得中・IME変換中は取り直さない。修飾キー付きのF5はブラウザーに渡す。 |

下部入力欄とインライン編集の日付・科目・金額は、キー入力を直接扱う。科目検索ではコードとローマ字の別名を使い、候補表示中のTabやEnterは候補を確定する。金額欄の `/` または `.` は、値が入っていて全選択中でないときに末尾へ `000` を追加する。これらの欄は物理キーボード向けで、貼り付けやカーソル位置への挿入はできない。摘要と補足は通常のテキスト入力で日本語を入力できる。

## 出力

| 操作 | 出力対象 |
| --- | --- |
| 印刷 | 画面の表示範囲にある明細をブラウザーで印刷する。 |
| PDF | 現在の検索条件をサーバーに送り、仕訳を取得し直す。税区分の表示は略称、名称、IDの順に解決する。ヘッダーと列見出しを各ページに表示する。補足は出力しない。金額範囲は絞り込みに適用するが、PDFの検索条件欄には印字しない。 |
| CSVエクスポート | 検索条件欄のボタンから、画面で取得済みの一覧全体をUTF-8 BOM付きで出力する。補足と親・補助科目の名前を含み、税区分列は出力しない。[CSVインポート](csv-import.md) の独自形式とは列の構成が異なる。 |

## 制約

単純仕訳のインライン編集には明細追加がない。複合仕訳に作り替える場合は複製した入力欄で明細を追加できる。仕訳テンプレートのDB定義は残っているが、入力・設定画面にテンプレートの操作はない。
