# メモ置き場

以下は旧資料に残る論点を、仕様を決めるときの質問にしたもの。確認には架空のデータを使う。

## 仕訳に戻るときの表示範囲

- 補助元帳の行から仕訳全体を開いたあと、元の科目・会計期・行へ戻れるか。確定済みの期では、参照できる内容と編集の可否をどう表示するか。
- 検索結果の合計は仕訳全体か、条件に合った明細だけか。借方2行のうち1行だけが科目・金額条件に合う架空の仕訳で、表示範囲、全検索結果、出力対象の違いを確認する。
- 入力候補から外した補助科目を、過去仕訳の検索・複製やCSVの照合でどう扱うか。履歴を表示できることと、現在の入力候補に出すことを各画面で確認する。 [仕訳入力と科目](../70-ideas/backlog.md#仕訳入力と科目)

## CSVを再現できる条件

- 同じファイルを設定変更後に読み直したとき、適用した列設定とルールをどの単位で識別するか。候補なし・複数候補・同じ優先度を、それぞれ登録前にどう伝えるか。
- 同じ日付・金額・摘要の別取引と、同じファイルを誤って再取込したケースをどう見分けるか。片側しかない明細や、複数行が1件の複合仕訳になるCSVでも確認する。
- 元の摘要、正規化した摘要、確定時の摘要をどこまで保持・出力するか。ルール変更後に過年度の帳簿の表示を再現できるか、確定後に元データを削除した場合も検討する。
- 取引先などの追加属性を、仕訳全体・仕訳明細・取込元のどこに持つか。「不明」「推定」「未設定」を区別する必要があるか。追加属性を使わない場合にも日常の入力手順が増えないかを確認する。 [CSV取込とデータの持ち出し](../70-ideas/backlog.md#csv取込とデータの持ち出し)

## 比較する会計期と決算書の表示

- 帳票だけで過年度を選ぶ場合、画面上で記帳先の当期と参照中の期をどう見分けるか。印刷・PDFにも参照中の会社・期・比較条件が同じように出るかを確認する。
- 比較対象の期がない場合、期が連続しない場合、期の長さが異なる場合の見せ方を決める。残高が0の科目と、比較できるデータがない科目をどう区別するか。
- 原価や損失の符号、小計と内訳、個人の元入金・控除前所得金額が読み取れるか。法人・個人の架空の仕訳を使い、決算書の画面とPDFを見比べる。 [会計期と帳票](../70-ideas/backlog.md#会計期と帳票)
