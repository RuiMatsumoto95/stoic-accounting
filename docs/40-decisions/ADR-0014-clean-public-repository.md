# ADR-0014 公開用リポジトリを新規に作り、旧履歴と内部資料を非公開で保管する


## 背景

公開前の監査で、旧Git履歴に個人の連絡先や環境を特定する情報が残っていた。現行のツリーを整理しても、過去のコミットに含まれる情報までは消えない。

## 決定

整理済みのコミットの追跡ファイルから公開用リポジトリを新規作成する。開発の経緯は旧リポジトリで非公開のまま保管する。引き継ぎ報告書と環境固有のバックアップ運用資料は公開ツリーから外し、必要な設計上の経緯を公開文書に要約する。

## 検討して採らなかった案

- 旧履歴を引き継ぎ、過去のコミットをすべて書き換えて公開する案。履歴とブランチ全体にわたる情報の除去と検証が必要だった。
- ローカルの作業フォルダをそのままコピーする方法。追跡対象外の環境設定や作業ファイルまで含まれるおそれがあった。

## 採用理由

公開に必要な追跡ファイルから始めれば、初回の公開対象を確認しやすい。旧履歴を非公開で保管することで、調査時の経緯は参照できる。

## 影響・制約

古い資料のコミット参照や内部報告書へのリンクは公開側で解決できない場合がある。公開文書では現行のソース・SQL・テストを根拠として示す。追跡ファイルに含まれていた個人情報は、ファイルの抽出後にも個別に点検する。

## 根拠

公開前監査の履歴比較と、公開方針D2・D3の2026-11-18の決定。現行リポジトリは公開用に切り出した初回コミットから始まり、既存の作業メモにも旧資料の公開範囲が記されている。 [作業メモ冒頭の注記](../../CLAUDE.md) [追跡対象外の設定](../../.gitignore)
