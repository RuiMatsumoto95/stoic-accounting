# ADR-0015 ソース公開を先に進め、認証・デモは後の段階に置く


## 背景

ソースコードを公開する作業と、第三者がインターネット上でアプリを使えるようにする作業には、異なる前提がある。現行のアプリでは認証や利用者ごとのアクセス制御が未実装だった。

## 決定

ソース公開を先の段階に置く。認証と公開デモは後の段階で扱う。ソース公開時のREADMEでは、実験段階であること、公開URLへ配置しないこと、実データを投入しないことを冒頭に明記する。

## 検討して採らなかった案

認証とデモがそろうまでソース公開を待つ進め方。公開用アプリの準備までを、先行するソース公開の条件に含めることになる。

## 採用理由

ソースを読める状態にするのに、第三者のアクセスを受けるアプリを稼働させる必要はない。現行のアクセス制御の限界を明示し、アプリを公開するための設計と検証は別の段階で行える。

## 影響・制約

ソース公開の段階で想定するのは手元での試用と架空データ。手元で画面を動かす場合も、設定したSupabaseのDBに接続する。実装済みのDB制約は仕訳などの整合性を守る。利用者の所属を認可する機能は未実装。

## 根拠

公開方針D4の2026-11-18の決定と公開前監査。先行公開の利用範囲は、READMEの冒頭とセキュリティ方針に反映されている。 [利用上の警告](../../README.md) [セキュリティ方針](../../SECURITY.md)
