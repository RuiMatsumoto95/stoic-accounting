# ADR-0013 ソースコードにApache-2.0を採用する


## 背景

ソースを公開するにあたり、自己ホスト、改変、再配布、他製品への組み込みを認める条件を決める必要があった。

## 決定

プロジェクトのソースコードにApache License 2.0を採用する。同梱フォントはSIL Open Font License 1.1を維持する。

## 検討して採らなかった案

- MITは条件が短く、利用・再配布のハードルが低い。選定時は、Apache-2.0にある明示的な特許許諾と商標の扱いを重視した。
- AGPL-3.0は、改変したサービスをネットワーク越しに提供する場合にもソースの提供を求める選択肢だった。選定時は、その条件の確認や運用を利用者と保守側に求めない方針を優先した。

## 採用理由

商用利用や他製品への組み込みを認める方向と合う。特許許諾や商標を許諾しない旨が条文に明示されている点も選定理由だった。依存パッケージと同梱フォントのライセンスは選定時に別途確認した。

## 影響・制約

リポジトリにライセンス本文と著作権表示を収録する。名称・商標と同梱フォントの扱いはルートREADMEに記載する。
