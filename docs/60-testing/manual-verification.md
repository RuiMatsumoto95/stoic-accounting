# ブラウザーでの確認

入力方式、フォーカス、画面遷移、端末での出力は、架空データを入れた試用環境で確認します。変更した画面から、保存や出力までの該当経路を選びます。

| 確認する経路 | 観察すること |
| --- | --- |
| 仕訳を入力・訂正する | 日本語入力を有効にしたまま日付・科目・金額を入力し、TabやEnterで候補の確定と欄の移動ができること。摘要・補足は日本語を入力できること。単純・複合仕訳の保存後に一覧を取り直し、日付・伝票番号・金額を確認する。 [仕訳日記帳のキー操作](../30-features/journals.md#キーボード操作) |
| 編集・検索から一覧に戻る | 保存に失敗したときに理由が表示されること。F5で検索条件とセル位置がどこまで復元されるか、編集中や変換中に再取得しないことを確認する。 [仕訳日記帳の検索と並び順](../30-features/journals.md#一覧の検索と並び順) |
| 会社・期間を切り替える | 未保存の入力があるときの確認、切替後に表示する会社・当期、別タブ切替後の再読み込み要求を確認する。法人・個人は初期科目と帳票の様式も確認する。 [設定](../30-features/settings.md) |
| 期首残高と年度確定 | 手動期首残高を保存・解除したときの導出値と差額、確定前の警告・エラー、確定と解除の順序を確認する。確定後の仕訳・期首残高・CSVで変更が止まり、解除後に入力できることを確認する。 [期首残高](../30-features/opening-balances.md)・[年度の確定と解除](../30-features/settings.md#年度の確定と解除) |
| CSVの取込と出力 | 架空のCSVを読み込み、確認一覧と本登録後の仕訳を照合する。警告が出るデータでは、行・列・理由が分かる状態かを確認する。エクスポートは件数、列、文字化けの有無を確認する。 [CSVインポート](../30-features/csv-import.md)・[仕訳日記帳の出力](../30-features/journals.md#出力) |
| 画面・印刷・PDF | 会社、会計期、科目、比較・ゼロ科目の条件を合わせて金額を照合する。日本語の表示、改ページ、ページごとの見出し、画面とPDFで対象範囲が異なる場合の出力を確認する。 [PDF生成](../10-architecture/pdf.md) |

結果には、対象コミット、OS・ブラウザー、日本語入力の状態、使った架空データの条件、操作と観察結果を残します。別のブラウザー・入力方式・競合条件は、実行した組み合わせが分かるように記録します。

旧検証記録では、Windows・Chrome・日本語入力有効の環境で、確定前チェック、確定・解除の順序、確定済みの期での仕訳変更の拒否、期首残高とCSVへの確定済み表示などを確認しています。Edge・Google日本語入力、複数タブでの同時編集、確定済みの期でのCSV本登録の拒否表示は未確認と記録されています。 [年度確定のアプリ確認記録](../../CLAUDE.md#ステップ3-年度の確定ロック2026-11-15本番db適用済みアプリ実装実機確認済み)
